# Mobile FinSec Spec

모바일 전자금융 보안 점검 자동화 데스크톱 앱의 설계 저장소입니다.

- 상태: 설계 v0.1. 구현 완료를 뜻하지 않습니다.
- 적용 환경: 승인된 QA 환경만. 운영 환경은 범위 밖입니다.
- 플랫폼: Android(AOS) → iOS → 웹.
- 원칙: 구현 전에 요구사항과 판정 기준, 화면·데이터·실행 계약을 명세합니다.
- 기준일: 2026-11-16
